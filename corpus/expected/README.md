# Canonical expectations — what Discovery must produce

Each file here states the `VerifiedIntent` a sentence should yield. Nothing in
them refers to the legacy compiler.

That is the point, and it is the milestone that ends shadow mode. During Phase
3 truth was *discovered* by disagreement:

    legacy compiler + hosted reader -> adjudication

After adjudication it must become:

    canonical expected VerifiedIntent <- Discovery Runtime

If the fixtures said "match what the compiler said", the compiler would remain
an implicit oracle after Phase 4 and could never be deleted — the suite would
be asserting agreement with the thing being removed. So an expectation records
the *semantic artifact*, not which reader won.

`adjudicated_winner` survives as **provenance about how the fixture was
obtained** — MODEL, COMPILER or SCHEMA. It is historical evidence, not part of
what Discovery has to reproduce, and no assertion reads it.
