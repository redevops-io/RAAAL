Investigations

A finding is an answer. An investigation is the question, and the work — which means it exists before there is anything to conclude, and it can close without ever producing an answer. Recording only the inquiries that found something would report a filtered history, and the filter runs in exactly the direction that flatters the platform.

The last column is the one that matters arithmetically. Deflation counts every configuration that was tried, not every configuration that worked, so trials spent on an inquiry that concluded nothing still raise the bar every later result in that lineage has to clear. An unrecorded search does not remove those trials — it only removes the platform's knowledge of them.

Why this is separate from findings

Every other artifact here describes something that happened. An investigation is the only one that can describe something that was tried and did not work out, which is why it had to be its own type rather than a status on a finding: a finding can record that something was concluded, but has no way to say an inquiry ran carefully and concluded the effect is not there.

Two failure modes become visible as a result. Silent abandonment — configurations tried and dropped without record, each one still a trial for deflation purposes. And conclusions with no inquiry — a finding asserting that work was done without saying what work. The first inflates every Sharpe ratio in a lineage; the second is a declaration with no realization, which this platform treats as a defect everywhere else.
