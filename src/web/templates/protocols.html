Evaluation protocols

methodology + evaluation protocol = performance. A protocol carries everything that shapes a number but is not part of the strategy: the trading calendar, transaction costs, execution lag, walk-forward grid, sealed holdout and data snapshot. Each is versioned and hashed, because changing any of them reprices every result measured under it.
