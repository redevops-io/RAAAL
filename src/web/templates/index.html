What this library does differently

A methodology here is executable data, not prose. Its lookback, covariance estimator, weight bounds and rebalance cadence are declared fields — so changing one necessarily changes the result, and two versions can be compared field by field rather than by eyeballing two curves.

A published figure names both the methodology and the evaluation protocol that produced it, because methodology + protocol = performance. The protocol carries the trading calendar, the transaction costs, the execution lag and the data snapshot — all of which move the number.

Corrections are published, not quietly applied. Superseded figures stay reachable and link forward to what replaced them.
